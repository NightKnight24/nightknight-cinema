📱 How to Use Bluetooth Remotes & Wi-Fi Phone Apps:

  • Bluetooth Remotes (Satechi, Apple Siri Remote, Firestick): Pair via macOS Bluetooth Settings. D-Pad arrows navigate tiles, Select launches, Back/Home returns home!
  • Wi-Fi Phone Apps (Unified Remote, Remote Mouse, Mobile Mouse): Connect over Wi-Fi. Arrow keys and Enter/Return directly control the Cinema interface with zero configuration.
